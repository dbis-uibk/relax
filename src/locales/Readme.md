# Localization files

There are three file types in this directory:

* "xy.json" files: they are used for localization and contain the texts that are used by the application. Those files are generated
from the master file.
* "language.csv": this is the master file and contains all localizations. After a change, generate the JSON files with "writeLanguageFiles.py"
* ".json" file: unknown purpose
* "xy.ts" files: unknown purpose
